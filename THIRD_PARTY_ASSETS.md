## ShareAlike

The Z-Anatomy-, Open3DModel- and BodyParts3D-derived GLBs and manifests must be distributed under CC BY-SA
with the attributions above. The rest of this project's code is unaffected
(the model is a separate asset).

The non-commercial file (`public/models/non-commercial/`) is distributed under
its own licences instead (CC BY-NC-SA 4.0 for the inner ear, CC BY-NC 4.0 for
the kidney). It is kept a separate file on purpose: NC and CC BY-SA content
can't be combined into one adapted work.

## Non-commercial models

The app is a free study tool, so it includes models licensed for
**non-commercial use only** (user decision, 2026-10-06): Z-Anatomy's inner ear
("Anatomy of the Inner Ear", University of Dundee, CC BY-NC-SA 4.0) and kidney
("Kidney", lissiecowley, CC BY-NC 4.0). While they are in, the app must stay
non-commercial: no ads, no paid features or subscriptions, no selling the app
or its models, no use in a paid course.

Everything non-commercial is kept in one place:

- one model file: `public/models/non-commercial/non-commercial.glb`;
- one manifest: `src/data/anatomy/z-anatomy/manifest-non-commercial.json`
  (each entry names its `source`);
- one switch: `INCLUDE_NON_COMMERCIAL` in `src/data/anatomy/z-anatomy/index.ts`;
- the licences: `MODEL_SOURCES` in `src/data/anatomy/z-anatomy/build.ts`
  (`commercialUse: false`).

A test (`build.test.ts`) checks that NC meshes are only in that file and that
the switch removes all of them, their model file and their credits.

### Going commercial

1. Set `INCLUDE_NON_COMMERCIAL = false` in
   `src/data/anatomy/z-anatomy/index.ts`. The dataset then drops the NC
   structures, model file and credits; course names and notes for them are
   simply unused.
2. Delete `public/models/non-commercial/` so the file is no longer served
   (`manifest-non-commercial.json` can stay, or delete it and its imports).
3. Rerun `npx tsx scripts/course/medintzfat/dump-structures.ts`,
   `course_names.py` and `summary_notes.py` (optional: drops the unused
   entries), then `npm run verify`.
4. Remove the NC row above and this section; check `MODEL_SOURCES` has no
   `commercialUse: false` source left.
5. Check the other assets too: CC BY-SA allows commercial use but requires
   attribution and ShareAlike; her course site's terms allow personal study
   use only (`data/course/medintzfat/`, course names — see
   `docs/COURSE_SOURCE.md`), and her summary was shared for this app.
   Commercial use needs permission from both.
   Also: Z-Anatomy's `Resources/Models/License.txt` says it includes
   "Brainder" and "White matter" from the University of Washington without
   naming a licence (likely in the brain meshes); confirm their terms first.
6. To fill the gap: a CC BY / CC BY-SA kidney or inner ear
   (`docs/MODEL_SOURCES.md`: BodyParts3D kidney, Human Reference Atlas kidney,
   the CC BY "Inner ear" on Sketchfab).
